Audit de Microsoft Sentinel

Microsoft Sentinel centralise les journaux et transforme les signaux en incidents. Un espace de travail sans connecteurs, sans règles analytiques ou sans automatisation ne détecte rien. Ces 4 contrôles vérifient la présence de Sentinel, le nombre de connecteurs de données actifs, les règles analytiques activées et les playbooks de réponse.

SEN-001

Microsoft Sentinel configuré

Sévérité élevée
Ce qui est vérifié
Un espace de travail Log Analytics doit exister avec Microsoft Sentinel activé, pour centraliser la collecte et l'analyse des événements de sécurité.
Valeur attendue
Au moins un espace de travail Sentinel.

Temps estimé1 h

RéférentielsANSSI Hygiène mesure 36RGPD Art.33

À savoir avant de commencer : Sentinel est facturé au volume de données ingérées : commencez par les sources gratuites ou peu volumineuses (activité Azure, alertes Defender, journaux Microsoft 365) et fixez un plafond quotidien. Si AuditM365 indique « aucun abonnement Azure visible », Sentinel existe peut-être déjà : attribuez d'abord le rôle Lecteur à l'application d'audit (dernière étape).

Corriger dans le portail

  1. Portail Azure > Espaces de travail Log Analytics > Créer : abonnement, groupe de ressources, région « France Central ».
  2. Portail Azure > Microsoft Sentinel > Créer > choisissez l'espace de travail > Ajouter. (Sentinel s'utilise aussi depuis le portail Defender.)
  3. Espace de travail > Utilisation et coûts estimés > Limite quotidienne : fixez un plafond.
  4. Pour qu'AuditM365 évalue Sentinel : Abonnements > l'abonnement > Contrôle d'accès (IAM) > Ajouter une attribution de rôle > « Lecteur » > l'application d'audit AuditM365.
Ouvrir la page dans le portail Microsoft ↗

Vérifier la correction

  • Le script affiche au moins un espace avec Sentinel = True.
  • Relancez un audit : SEN-001 passe à Conforme (après l'attribution du rôle Lecteur à l'application d'audit).

Documentation Microsoft : learn.microsoft.com/en-us/azure/sentinel/quickstart-onboard

SEN-002

Connecteurs de données Sentinel actifs

Sévérité élevée
Ce qui est vérifié
Au moins 5 connecteurs de données doivent être actifs dans Microsoft Sentinel pour couvrir les principales sources de journaux.
Valeur attendue
5 connecteurs de données actifs au moins.

Temps estimé1 à 2 h

RéférentielsANSSI Hygiène mesure 36RGPD Art.33

À savoir avant de commencer : Chaque connecteur ajoute des données facturées : vérifiez le volume estimé de chacun (page du connecteur) et la limite quotidienne de l'espace. Les connecteurs Microsoft 365 et Defender XDR apportent l'essentiel pour un tenant Microsoft 365.

Corriger dans le portail

  1. Microsoft Sentinel > Gestion du contenu > Hub de contenu : installez les solutions « Microsoft Entra ID », « Microsoft 365 », « Microsoft Defender XDR », « Azure Activity ».
  2. Configuration > Connecteurs de données : ouvrez chaque connecteur > « Ouvrir la page du connecteur » > connectez (journaux de connexion et d'audit Entra, Exchange / SharePoint / Teams, incidents Defender XDR).
  3. Visez au moins 5 connecteurs à l'état « Connecté ».
Ouvrir la page dans le portail Microsoft ↗

Vérifier la correction

  • Le script affiche au moins 5 connecteurs.
  • Relancez un audit : SEN-002 passe à Conforme.

Documentation Microsoft : learn.microsoft.com/en-us/azure/sentinel/connect-data-sources

SEN-003

Règles analytiques Sentinel actives

Sévérité moyenne
Ce qui est vérifié
Au moins 10 règles analytiques doivent être activées dans Microsoft Sentinel pour détecter les menaces et créer des incidents.
Valeur attendue
10 règles analytiques actives au moins.

Temps estimé1 à 2 h

RéférentielsANSSI Hygiène mesure 36ANSSI Hygiène mesure 40RGPD Art.33

À savoir avant de commencer : Activez les règles par lots et surveillez le volume d'incidents la première semaine : mieux vaut dix règles dont les incidents sont lus que cent règles que personne ne suit. Les règles des solutions du Hub de contenu (Microsoft Entra ID, Microsoft 365) sont prêtes à l'emploi et cartographiées MITRE ATT&CK.

Corriger dans le portail

  1. Microsoft Sentinel > Configuration > Analyse > Modèles de règle : filtrez par sources de données connectées et par gravité Élevée et Moyenne.
  2. Pour chaque modèle utile : « Créer une règle » en gardant la requête et la fréquence proposées. Activez d'abord : connexions depuis des pays inhabituels, pulvérisation de mots de passe, ajout à un rôle privilégié, création de règle de transfert de boîte, consentement à une application à risque.
  3. Vérifiez qu'au moins 10 règles sont « Activées ».
Ouvrir la page dans le portail Microsoft ↗

Vérifier la correction

  • Le script affiche au moins 10 règles activées.
  • Relancez un audit : SEN-003 passe à Conforme.

Documentation Microsoft : learn.microsoft.com/en-us/azure/sentinel/detect-threats-built-in

SEN-004

Automatisation Sentinel (playbooks)

Sévérité faible
Ce qui est vérifié
Au moins une règle d'automatisation ou un playbook doit être configuré dans Microsoft Sentinel pour automatiser la réponse aux incidents.
Valeur attendue
Au moins un playbook ou une règle d'automatisation.

Temps estimé1 h

RéférentielsANSSI Hygiène mesure 40RGPD Art.33

À savoir avant de commencer : Commencez par des automatisations sans risque (attribuer l'incident, ajouter une étiquette, prévenir par e-mail ou Teams) avant des actions de réponse (désactiver un compte), qui doivent être testées sur un compte de test.

Corriger dans le portail

  1. Microsoft Sentinel > Configuration > Automatisation > Créer > Règle d'automatisation : déclencheur « Quand l'incident est créé », condition gravité Élevée, action « Affecter le propriétaire » et « Ajouter une étiquette ».
  2. Pour une notification : Hub de contenu > solution « SOAR Essentials » > playbook de notification Teams ou e-mail, puis action « Exécuter le playbook » dans la règle.
Ouvrir la page dans le portail Microsoft ↗

Vérifier la correction

  • Le script affiche au moins une règle d'automatisation.
  • Relancez un audit : SEN-004 passe à Conforme.

Documentation Microsoft : learn.microsoft.com/en-us/azure/sentinel/automate-incident-handling-with-automation-rules
